4, x)             # → [-2, 2]ssolve([x+y-1, x-y-3], [x,y])  # system of equationssimplify(sin(x)**2 + cos(x)**2) # → 1factor(x**3 - 6*x**2 + 11*x - 6)expand((x+1)**5)```### Matrices — Numeric```pythonA = mat([[1,2],[3,4]])   # numpy arrayb = mat([1,0])A @ b                    # matrix multiplydet(A)inv(A)eig(A)                   # eigenvalues + eigenvectorslsolve(A, b)             # solve Ax = brank(A)null(A)                  # null spacenorm(v)```### Matrices — Symbolic```pythonA = M([[1, x], [x, 1]])  # sympy MatrixA.det()A.inv()A.eigenvals()A.eigenvects()A.rref()                 # row reduction```### Vector CalculusAll symbolic, operates on `x, y, z` by default.```pythonf = x**2 + y**2 + z**2grad(f)                  # → [2x, 2y, 2z]laplacian(f)             # → 6F = [x*y, y*z, z*x]div(F)                   # → y + z + xcurl(F)                  # → [-y, -z, -x]```2D case (pass custom vars):```pythonf2 = x**2 + y**2grad(f2, vars=(x, y))```### Polynomials```pythonroots([1, 0, -4])        # x² - 4 = 0  → [2, -2]p = polyfit(xdata, ydata, 2)polyval(p, 3.5)```### Numerical Helpers```pythoninterp1(xdata, ydata, xq)                   # 1D interpolationfzero(lambda v: v**2 - 2, [1, 2])           # root findingode45(lambda t,y: [-y[0]], [0,5], [1.0])    # ODE solver (RK45)fplot(sin(x)/x, x, -10, 10)                 # quick symbolic plot```---## Physics Constants — `packs/physics`Always loaded. wipe saved state```If a variable silently disappeared, the session startup will warn you which names couldn't be serialized.---## Tips**Pretty symbolic output** is enabled automatically (`sp.init_printing()`).  Use `pretty(expr)` to force it in plain console contexts.**Evaluate a symbolic expression numerically:**```pythonexpr = sin(x)**2 + cos(x)**2float(expr.subs(x, 1.2).evalf())```**Convert symbolic result to numpy function:**```pythonf_sym = sin(x) * exp(-x)f_num = sp.lambdify(x, f_sym, "numpy")f_num(np.linspace(0, 10, 500))```**Matrix multiply** is always `@`, never `*`:```pythonA @ B    # matrix productA * B    # element-wise  ← usually not what you want```
